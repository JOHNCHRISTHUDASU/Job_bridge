# JobBridge

## Smart Local Employment and Recruitment Platform

JobBridge is a web application designed to connect local job seekers with employers. It aims to make finding local employment and recruiting workers easier.

### Features

- Separate access for job seekers and employers
- User registration and login
- Job posting and job application management
- MySQL database integration
- AI-powered features
- Multilingual interface support

### Technologies Used

- Python
- Flask
- MySQL
- HTML, CSS, and JavaScript

### Setup

1. Clone or download the project.
2. Install the required Python packages from `requirements.txt`.
3. Configure the required environment variables in a local `.env` file.
4. Set up the MySQL database using a safe database script.
5. Run the Flask application using the instructions provided in the project.

### Security

Do not commit API keys, passwords, personal information, or private user-uploaded files.
